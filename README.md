# Применение нейронных сетей для анализа сетевого трафика и предотвращения вторжений (VKRAiProject)

[cite_start]Репозиторий содержит гибридную интеллектуальную систему обнаружения вторжений (Intrusion Detection System, IDS) для анализа сетевого трафика в режиме реального времени[cite: 278, 695]. [cite_start]Проект разработан в рамках выпускной квалификационной работы[cite: 47, 695]. 

[cite_start]Программный комплекс собирает сетевые пакеты, агрегирует их в потоки и применяет модели машинного обучения для выявления известных атак и скрытых аномалий[cite: 562, 699].

## Основные возможности

* [cite_start]**Потоковый анализ в реальном времени:** Асинхронный перехват трафика осуществляется с помощью библиотеки Scapy[cite: 618, 619]. [cite_start]Пакеты группируются в двунаправленные сеансы связи по 5 базовым параметрам (IP-адреса, порты источника/назначения, протокол транспортного уровня)[cite: 622, 623].
* [cite_start]**Гибридная интеллектуальная архитектура:** Классификация известных киберугроз выполняется с помощью алгоритма Random Forest, обученного на датасетах CICIDS 2018 и SCVIC-APT[cite: 280, 640]. [cite_start]Параллельно для поиска неизвестных атак (zero-day) применяется нейронная сеть-автоэнкодер (TensorFlow/Keras), анализирующая отклонения по ошибке реконструкции данных[cite: 642, 643].
* [cite_start]**Объяснимый ИИ (Explainable AI, XAI):** В систему интегрирована библиотека LIME, которая локально интерпретирует решения классификатора и автоматически выделяет 6 наиболее весомых признаков сетевого соединения[cite: 661, 662, 664]. 
* [cite_start]**Глубокое извлечение признаков:** Конвейер динамически рассчитывает более 70 статистических и временных метрик, формируя стандартизированный 39-мерный вектор данных для нейросети[cite: 630, 681, 705].
* [cite_start]**Интерактивный веб-интерфейс:** Панель мониторинга построена на микрофреймворке Flask[cite: 649]. [cite_start]Использование Flask-SocketIO и протокола WebSockets позволяет мгновенно транслировать результаты инференса (вероятности классов, уровни риска) напрямую в браузер аналитика без перезагрузки страниц[cite: 650, 654, 686].
* [cite_start]**Визуализация инцидентов:** Система автоматически генерирует графики столбчатых диаграмм с помощью Plotly для отображения 5 признаков с наибольшей абсолютной ошибкой реконструкции[cite: 668]. 

## Системные требования

* [cite_start]**Операционная система:** Windows 10 / 11 (64-bit)[cite: 610].
* [cite_start]**Сетевой драйвер:** Установленный Npcap (строго обязателен для захвата сетевых пакетов средствами Scapy)[cite: 405, 610].
* [cite_start]**Среда выполнения:** Python 3.9[cite: 610].
* [cite_start]**Оборудование:** Многоядерный процессор (от 4 ядер, 2.0 ГГц), не менее 8 ГБ оперативной памяти[cite: 610].

## Используемые технологии

* [cite_start]**Backend & Web:** Python 3.9, Flask, Flask-SocketIO, Werkzeug, simple-websocket[cite: 593, 610, 748].
* [cite_start]**Анализ трафика:** Scapy, psutil[cite: 569, 600, 748].
* [cite_start]**Машинное обучение & ИИ:** TensorFlow, Keras, scikit-learn, lime[cite: 576, 584, 585, 748].
* [cite_start]**Обработка данных:** pandas, NumPy, joblib, dill, pickle[cite: 573, 574, 589, 748].
* [cite_start]**Визуализация:** Plotly, Chart.js, HTML/CSS/JS[cite: 597, 655, 658, 748].

## Установка и запуск

1. Клонируйте данный репозиторий на свой компьютер:
   [cite_start]`git clone https://github.com/Pergunte1/VKRAiProject.git` [cite: 726]
2. Перейдите в директорию проекта:
   `cd VKRAiProject`
3. Установите необходимые зависимости из файла:
   [cite_start]`pip install -r requirements.txt` [cite: 607, 748]
4. [cite_start]Убедитесь, что в системе установлен драйвер Npcap для перехвата пакетов[cite: 608, 610].
5. Запустите серверное веб-приложение:
   [cite_start]`python application.py` [cite: 407, 748]
6. Откройте современный веб-браузер и перейдите по адресу:
   [cite_start]`http://localhost:5000`[cite: 369, 407, 610].

## Структура проекта

* [cite_start]`application.py` — Главный модуль, содержащий логику веб-сервера (Flask), маршрутизацию запросов и запуск фонового асинхронного потока перехвата трафика[cite: 619, 649, 748].
* [cite_start]`requirements.txt` — Файл зависимостей с указанием точных версий используемых библиотек[cite: 607, 748].
* [cite_start]`flow/` — Директория с классами объектной модели сети: `PacketInfo.py` (разбор сырых пакетов), `Flow.py` (агрегация и контроль сессий) и `FlowFeature.py` (хранение извлеченных статистических признаков)[cite: 409, 748].
* [cite_start]`models/` — Директория для статической десериализации, содержащая сохраненные веса (`autoencoder_39ft.hdf5`, `model.pkl`), препроцессоры (`preprocess_pipeline_AE_39ft.save`, `scaler.pkl`) и объекты объяснителя XAI (`explainer`)[cite: 636, 706, 748].
* [cite_start]`static/` — Статические ресурсы: таблицы стилей (`main.css`, `media.css`), клиентские скрипты (`application.js`)[cite: 425, 748].
* [cite_start]`templates/` — HTML-шаблоны пользовательского интерфейса, включая главную панель управления (`index.html`) и страницу углубленного анализа потока (`detail.html`)[cite: 427, 660, 748].

## Журналирование и аудит

[cite_start]Система дублирует все извлеченные входные векторы и соответствующие им результаты классификации (уровень угрозы, предсказанный класс) в локальные текстовые файлы `input_logs.csv` и `output_logs.csv`[cite: 428, 671, 717]. [cite_start]Это позволяет в дальнейшем проводить детальное расследование инцидентов и валидацию моделей[cite: 511, 692].
