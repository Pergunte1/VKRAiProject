# Применение нейронных сетей для анализа сетевого трафика и предотвращения вторжений (VKRAiProject)

Репозиторий содержит гибридную интеллектуальную систему обнаружения вторжений (Intrusion Detection System, IDS) для анализа сетевого трафика в режиме реального времени. Проект разработан в рамках выпускной квалификационной работы. 

Программный комплекс собирает сетевые пакеты, агрегирует их в потоки и применяет модели машинного обучения для выявления известных атак и скрытых аномалий.

## Основные возможности

* **Потоковый анализ в реальном времени:** Асинхронный перехват трафика осуществляется с помощью библиотеки Scapy. Пакеты группируются в двунаправленные сеансы связи по 5 базовым параметрам (IP-адреса, порты источника/назначения, протокол транспортного уровня).
* **Гибридная интеллектуальная архитектура:** Классификация известных киберугроз выполняется с помощью алгоритма Random Forest, обученного на датасетах CICIDS 2018 и SCVIC-APT. Параллельно для поиска неизвестных атак (zero-day) применяется нейронная сеть-автоэнкодер (TensorFlow/Keras), анализирующая отклонения по ошибке реконструкции данных.
* **Объяснимый ИИ (Explainable AI, XAI):** В систему интегрирована библиотека LIME, которая локально интерпретирует решения классификатора и автоматически выделяет 6 наиболее весомых признаков сетевого соединения. 
* **Глубокое извлечение признаков:** Конвейер динамически рассчитывает более 70 статистических и временных метрик, формируя стандартизированный 39-мерный вектор данных для нейросети.
* **Интерактивный веб-интерфейс:** Панель мониторинга построена на микрофреймворке Flask. Использование Flask-SocketIO и протокола WebSockets позволяет мгновенно транслировать результаты инференса (вероятности классов, уровни риска) напрямую в браузер аналитика без перезагрузки страниц.
* **Визуализация инцидентов:** Система автоматически генерирует графики столбчатых диаграмм с помощью Plotly для отображения 5 признаков с наибольшей абсолютной ошибкой реконструкции. 

## Системные требования

* **Операционная система:** Windows 10 / 11 (64-bit).
* **Сетевой драйвер:** Установленный Npcap (строго обязателен для захвата сетевых пакетов средствами Scapy).
* **Среда выполнения:** Python 3.9.
* **Оборудование:** Многоядерный процессор (от 4 ядер, 2.0 ГГц), не менее 8 ГБ оперативной памяти.

## Используемые технологии

* **Backend & Web:** Python 3.9, Flask, Flask-SocketIO, Werkzeug, simple-websocket.
* **Анализ трафика:** Scapy, psutil.
* **Машинное обучение & ИИ:** TensorFlow, Keras, scikit-learn, lime.
* **Обработка данных:** pandas, NumPy, joblib, dill, pickle.
* **Визуализация:** Plotly, Chart.js, HTML/CSS/JS.

## Установка и запуск

1. Клонируйте данный репозиторий на свой компьютер:
   `git clone https://github.com/Pergunte1/VKRAiProject.git`
2. Перейдите в директорию проекта:
   `cd VKRAiProject`
3. Установите необходимые зависимости из файла:
   `pip install -r requirements.txt`
4. Убедитесь, что в системе установлен драйвер Npcap для перехвата пакетов.
5. Запустите серверное веб-приложение:
   `python application.py`
6. Откройте современный веб-браузер и перейдите по адресу:
   `http://localhost:5000`.

## Структура проекта

* `application.py` — Главный модуль, содержащий логику веб-сервера (Flask), маршрутизацию запросов и запуск фонового асинхронного потока перехвата трафика.
* `requirements.txt` — Файл зависимостей с указанием точных версий используемых библиотек.
* `flow/` — Директория с классами объектной модели сети: `PacketInfo.py` (разбор сырых пакетов), `Flow.py` (агрегация и контроль сессий) и `FlowFeature.py` (хранение извлеченных статистических признаков).
* `models/` — Директория для статической десериализации, содержащая сохраненные веса (`autoencoder_39ft.hdf5`, `model.pkl`), препроцессоры (`preprocess_pipeline_AE_39ft.save`, `scaler.pkl`) и объекты объяснителя XAI (`explainer`).
* `static/` — Статические ресурсы: таблицы стилей (`main.css`, `media.css`), клиентские скрипты (`application.js`).
* `templates/` — HTML-шаблоны пользовательского интерфейса, включая главную панель управления (`index.html`) и страницу углубленного анализа потока (`detail.html`).

## Журналирование и аудит

Система дублирует все извлеченные входные векторы и соответствующие им результаты классификации (уровень угрозы, предсказанный класс) в локальные текстовые файлы `input_logs.csv` и `output_logs.csv`. Это позволяет в дальнейшем проводить детальное расследование инцидентов и валидацию моделей.
